2. Explanation of Hack Computer Implementation (Part A)

The Hack computer is a 16-bit Von Neumann architecture machine comprising three core functional units:

2.1 Central Processing Unit (CPU.hdl)

The CPU executes 16-bit Hack instructions. A-instructions (bit 15 = 0) load addresses into the A register. C-instructions (bit 15 = 1) execute ALU operations between the D register and A/Memory, route results to target destinations (A, D, M), and evaluate jump logic against status flags (zr, ng) to steer the Program Counter (PC).

2.2 Memory System (Memory.hdl)

Unifies RAM16K (0x0000 - 0x3FFF), Screen memory (0x4000 - 0x5FFF), and Keyboard memory (0x6000). Demultiplexes read and write operations based on upper address bits 14 and 13.

2.3 Integrated Computer (Computer.hdl)

Coordinates ROM32K, CPU, and Memory into an integrated system running stored machine code in real time.

3. Explanation of Two-Pass Assembler (assembler.py)

  • Pass One (Label Resolution): Scans assembly line by line, ignores comments and blanks. Captures labels like (LOOP) and maps them to the upcoming ROM address in the symbol table without consuming ROM cycles.
  • Pass Two (Binary Code Generation): Re-scans instructions. Translates @value A-instructions into 15-bit binary addresses. Allocates RAM variables starting at RAM address 16. Parses C-instructions into comp, dest, and jump binary fields.

9. Programming Mistake Encountered & Resolution

Encountered Error: ValueError: Line 85: Invalid comp field 'M+D' in instruction 'M=M+D'.

Root Cause: The Hack ALU hardware specifications designate addition as D+M and D+A (with register D as primary). Writing M+D violated strict Hack instruction mnemonics.

Fix: Corrected the instruction in Box.asm to M=D+M, and also enhanced assembler.py with commutative aliases (M+D, A+D, etc.) for developer convenience.
