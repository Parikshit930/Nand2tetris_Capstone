CPU.hdl Verified

Decodes 16-bit instructions into A-instructions (bit 15=0) and C-instructions (bit 15=1). Controls the ARegister, DRegister, ALU, writeM, and Program Counter (PC) jump evaluations.

Mux16(a=aluOut, b=instruction, sel=isA, out=aIn);
ALU(x=D, y=AorM, ... out=aluOut, zr=zr, ng=ng);
PC(in=A, load=doJump, inc=true, reset=reset);
Memory.hdl Verified

Unifies RAM16K (0x0000..0x3FFF), Screen (0x4000..0x5FFF), and Keyboard (0x6000) into a single 15-bit address space governed by upper bits address[14..13].

DMux(in=load, sel=address[14], a=loadRAM, b=loadIO);
RAM16K(in=in, load=loadRAM, address=address[0..13]);
Screen(in=in, load=loadScreen, address=address[0..12]);
Computer.hdl Verified

Top-level chip tying ROM32K, CPU, and Memory together into a synchronized closed-loop architecture running on system clock cycles.

ROM32K(address=pc, out=instruction);
CPU(inM=inM, instruction=instruction, reset=reset);
Memory(in=outM, load=writeM, address=addressM);
